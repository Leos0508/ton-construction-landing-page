# TON Construction Landing Page

A single-page marketing site for a fictional construction company, built as a portfolio piece to demonstrate design and frontend implementation.

The design is mine. The code was generated by AI from my instructions, then reviewed and adjusted by hand. I directed the layout, type, motion, and responsive behaviour, wrote the wireframe, and iterated on the output. Treat it as a sample of how I design and how I work with AI tooling, not as a product that shipped.

Everything here is static HTML, CSS, and a handful of small scripts. No server, no database, no API keys.

## Stack

- Astro 7, static output, TypeScript strict
- Tailwind CSS v4 through `@tailwindcss/vite`
- shadcn/ui theme tokens, `radix-nova` preset
- React components for the navbar, buttons, and logo, rendered to static HTML with no hydration
- Tabler icons
- Fontsource for self-hosted type: DM Sans, Bebas Neue, Instrument Serif
- `astro:assets` for responsive WebP renditions
- sharp-cli for converting source images

## Features

- Fixed navbar that retracts on scroll and returns when the pointer reaches the top strip, disabled on touch
- Full-viewport mobile menu with a blurred backdrop
- Hero with an animated rule and a staggered blur reveal
- Scroll-triggered reveals, one pass per element
- Project carousel with native scroll snapping, one card on phones and three on desktop
- Project cards that open a native dialog with a blurred backdrop
- Smooth in-page anchors and a back-to-top control at the end of the page
- Respects `prefers-reduced-motion` throughout

## Getting started

```sh
pnpm install
pnpm dev      # http://localhost:4321
pnpm build    # writes dist/
pnpm preview  # serves dist/ locally
```

## Analytics

Cloudflare Web Analytics is wired in and stays silent until a token exists.

1. Cloudflare dashboard, Web Analytics, Add a site
2. Copy the beacon token
3. Set `PUBLIC_CF_ANALYTICS_TOKEN` in the Worker environment variables
4. Redeploy

Locally, copy `.env.example` to `.env` and fill it in.

Cookieless, so no consent banner, and it reports Core Web Vitals next to page
views. Roughly a third of visitors run a blocker that drops the beacon, so read
the numbers as a trend rather than a census.

## Deploy

Static output, so any host works. Build command `pnpm build`, output directory `dist`.

### Cloudflare

The repo is configured for Workers static assets, which is what a Git-connected
Worker build deploys.

Settings in the dashboard:

| Setting | Value |
| --- | --- |
| Root directory | leave empty |
| Build command | `pnpm build` |
| Deploy command | `npx wrangler deploy` |
| Environment variable | `NODE_VERSION=22` |

Root directory is the folder the build runs in, not where the output goes.
Pointing it at `dist` fails with `Failed: root directory not found`, because
`dist` does not exist until after the build has run.

`wrangler.toml` points the assets block at `./dist`, and `public/_headers`
carries the cache and security headers, which `wrangler` copies along with the
build output.

For a manual deploy from your machine:

```sh
pnpm cf:login   # opens a browser once
pnpm deploy     # builds, then uploads dist/
```

If you would rather use Pages, create a Pages project instead of a Worker, set
the build output directory to `dist`, and swap the `[assets]` block in
`wrangler.toml` for `pages_build_output_dir = "dist"`.

### Other hosts

| Host | Notes |
| --- | --- |
| Netlify | Free tier, includes form handling if a contact form is added |
| Vercel | Hobby tier is non-commercial, use Pro for a company site |
| GitHub Pages | Free, no preview deploys |

Set `site` in `astro.config.mjs` once the domain is known.
